Pasting text from a PDF sometimes breaks the prompt

Pasting text from a PDF sometimes breaks the prompt with a JSON parse error. Find out why and fix it.

Found it. The reader used Node’s readline, which also breaks lines at U+2028 and U+2029. Text pasted from a PDF often holds those, so one JSON record was split into two invalid lines.

  • Switched to pi’s RpcClient, which splits records on \n only
  • Added test/reader.test.ts

The test passes. The edits are in Source Control, ready to review and commit.
