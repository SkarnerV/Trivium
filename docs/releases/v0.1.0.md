Trivium's first preview release brings coding, research and writing into one desktop workspace, powered by the pi agent SDK.

- Three apps with their own models, tools, extensions and running sessions.
- Live agent steps, command output, attachments, questions and approvals.
- Subagent activity, live progress, usage-limit explanations and failed-step counts.
- Copy replies, edit or fork earlier messages, and start a conversation without choosing a folder.
- Review code diffs, preview research notes with sources, and accept or reject tracked writing changes.
- Built-in provider logins, custom model endpoints, MCP support and project trust.

### Downloads

- **Windows x64:** download and run `Trivium-0.1.0-Windows-x64.exe`. This single portable executable includes the app and its runtime; no installer or separate archive is required.
- **macOS Apple Silicon:** open `Trivium-0.1.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.1.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
