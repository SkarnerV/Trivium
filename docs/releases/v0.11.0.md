Trivium 0.11.0 lets other apps use Trivium's models through a local API proxy, tracks what shell commands change, and makes diagrams zoomable.

- **API proxy**: Settings → API proxy serves OpenAI Chat Completions and Anthropic Messages requests on this computer, using every provider and login set up in Trivium. Apps connect with named keys made on the page.
- **Shell changes tracked**: files that bash or PowerShell commands rewrite, create or delete now show in Code's Changes view with a diff and a revert button.
- **Zoomable diagrams**: zoom, drag and fit diagrams and transcript images; download a diagram as SVG or PNG, or open it in the side panel.
- **Open in VS Code on Windows**: works again, jumping straight to the file and line.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.11.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.11.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.11.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.11.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
