Trivium 0.13.1 adds Orchestrator work mode and expands the controls and information available for subagents.

- **Orchestrator work mode:** in a project Code session, ask the agent to scout and split work across subagents, with parallel writers in managed worktrees. Select it in the message box or set the default in Settings → Code.
- **Subagent sessions:** stop an individual workflow or background subagent, see its thinking level and context use, and hover over its row for its status and work. The session drawer replaces the side panel while open.
- **Changes and permissions:** subagents' project edits appear in This session and can be reverted. Native children use Code's permission gate; external CLI agents continue under their own tools' permissions. Background edits are picked up when the agent reports back, when its run ends, or after 30 minutes at the latest.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.13.1/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.13.1-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.13.1-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.13.1-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
