Trivium 0.14.0 replaces Changes and History with a Source Control tab and adds a Files tab to the Code panel.

- **Source Control:** push and pull, a commit message the session's model can draft, staging, discard, merge conflicts and every branch's history in one tab. Commits can name their session, and History links back to it.
- **Files:** the project as a tree with git status and a name filter. In both tabs the picked file opens below the list, as its diff or as the whole file with changed lines marked.
- **Summary cards** now open from the header button as one list over the thread.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.14.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.14.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.14.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.14.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
