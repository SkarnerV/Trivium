Trivium 0.14.1 fixes message queueing and dispatch edge cases, hardens Orchestrator and subagent runs, and fixes the API proxy's `/v1/models` response and CRLF memory files.

- **Message queue and dispatch:** stopping a run holds only what was queued at that moment and marks it "Held", messages sent during compaction or extension preparation are no longer lost, Stop and Delete reclaim unsent messages, and failed sends return ahead of what you typed since without losing attachments.
- **Orchestrator and subagents:** Orchestrator now uses one forked writer in the background while keeping the turn open for follow-ups. Workflow `gate` and `acceptance.verify` commands follow Code's permission gate, patches match each writer's own run, subagents waiting on answers stay running, and your own edits made during subagent or background work are protected from session revert.
- **API proxy and Memory:** `/v1/models` now includes `context_window`, `max_output_tokens`, Anthropic's `max_input_tokens`, `max_tokens` and `capabilities`, and input/output modalities. Memory files saved with Windows (CRLF) line endings now display and preserve their line endings on edits.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.14.1/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.14.1-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.14.1-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.14.1-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
