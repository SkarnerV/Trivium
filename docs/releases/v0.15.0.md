Trivium 0.15.0 adds a Launch button that starts your project's app and its Docker Compose services, and makes the API proxy's key optional.

- **Launch:** a session with a project can run the shell tasks in `.vscode/tasks.json`, starting any `docker-compose` task they depend on first. Every launch shows what will run and asks first. Compose projects are shared between sessions and stopped, without removing volumes, when the session is deleted or Trivium quits. The button shows only when there is something to launch.
- **API proxy:** no key is needed by default; Settings → API proxy → **Require an API key** turns the check back on, and a proxy already set up keeps requiring one until you turn it off. Without a key, only requests to `localhost`, `host.docker.internal` or, with the network allowed, a local IP address are accepted. Two Triviums sharing a profile no longer undo each other's proxy settings.
- **Thread:** long tool call previews no longer make the thread scroll sideways.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.15.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.15.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.15.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.15.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
