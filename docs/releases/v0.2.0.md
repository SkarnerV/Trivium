Trivium 0.2.0 adds memory across sessions, a Usage page, MCP server management and git in Code sessions.

- **Memory in every mode**, with a Memory page to see, edit and delete what the agent remembers everywhere, per workspace and in the daily log.
- **Settings → Usage**: tokens and estimated cost from every session, by mode, model and session, with a 12-month activity calendar.
- **Settings → Connectors**: add, edit, sign in to and switch off MCP servers, and choose how their tools reach the agent.
- **Git in Code sessions**: the branch in the header with a plain-words summary, and a Git view of changed files and diffs.
- **Preview panel**: open HTML, Markdown, CSV, text and images from the project as tabs beside the conversation.
- **Reply timing**, queue (`↵`) or steer (`⌥↵`) mid-run, pinned projects and sessions, and one composer button for model and effort.
- Fixes for retrying an unchanged message, mode switching while a session loads, Windows toasts, ChatGPT plan models and more.

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.2.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.2.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.2.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.2.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
