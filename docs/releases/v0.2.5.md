Trivium 0.2.5 updates itself from inside the app, speaks Simplified Chinese and Japanese, and shows the services a session leaves running.

- **Updates from inside the app**: a row above **Settings** offers a new release; one click downloads it, checks its checksum, swaps it in and restarts. Copies installed from 0.2.0 or earlier still need this one update by hand.
- **Languages**: **Settings → General → Language** switches between English, 简体中文 and 日本語, or follows the system.
- **Services**: dev servers and other processes a session's commands leave running are listed in Code's side panel, with their ports and output, and can be stopped there.
- **Permission levels** are now Always ask, Approve for me and Bypass permissions, picked from the composer.
- Shortcuts use Ctrl on Windows, drafts are kept when switching sessions, a retried request no longer leaves an error card, and a user's own memory extension no longer conflicts with the built-in one.

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.2.5/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.2.5-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.2.5-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.2.5-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
