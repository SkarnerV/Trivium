Trivium 0.3.0 puts a session's services, git status and changes in summary cards beside the conversation, and keeps the conversation on screen after it is compacted.

- **Summary cards**: in Code sessions, one header button shows Services, Git and Changes cards beside the conversation; a card opens its details as a tab in the side panel, which now holds its views and previewed files as tabs.
- **History kept after compaction**: earlier messages stay above a "Conversation compacted above" divider, also after a restart and in exports. Compaction shows its progress until it finishes, automatic compaction included, and can be stopped.
- **Services**: a command that leaves several programs running lists each one as its own service, and on Windows programs started with `Start-Process` or `start` are found too.

Copies running 0.2.5 can update from inside the app. Copies installed from 0.2.0 or earlier need to be updated by hand once.

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.3.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.3.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.3.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.3.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
