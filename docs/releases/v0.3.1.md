Trivium 0.3.1 fixes updating from inside the app on Windows.

- **Update and restart now installs on Windows.** In 0.2.5 and 0.3.0 it downloaded the new version and quit Trivium, but never put the new version in place, so Trivium was still the old version when opened again.
- The unpacked copy of the new version that such an update left in Trivium's folder (`.trivium-update`) is deleted when Trivium starts.

**On Windows with 0.2.5 or 0.3.0, download this version by hand once.** Those versions have the broken updater, so updating from inside the app won't work for them. Close Trivium, download `Trivium-0.3.1-Windows-x64.zip` below, extract it to a new folder and run `Trivium.exe` from there. Sessions, logins and settings live in your user folder, so nothing is lost, and the old Trivium folder can then be deleted. Updates from 0.3.1 on install from inside the app.

On macOS, updating from inside the app works as before.

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.3.1/CHANGELOG.md) for the full list, and the [0.3.0 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.0) for what 0.3.0 added.

### Downloads

- **Windows x64:** download `Trivium-0.3.1-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.3.1-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.3.1-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
