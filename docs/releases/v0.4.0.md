Trivium 0.4.0 shows two sessions side by side, queues messages sent during a run, and gives Code its own permission gate.

- **Split view**: open a session beside the one on screen from its sidebar menu, with Ctrl/Cmd-click, by dragging it onto either half of the window, or with Ctrl/Cmd+Shift+\. Each mode remembers its split across restarts.
- **Message queue**: messages sent while the agent runs wait above the message box and go out when the run ends. Each one can be steered into the running turn, deleted or edited.
- **Permission modes in Code**: Trivium's own gate replaces pi-permission-system, with **Always ask**, the new **Accept edits**, **Approve for me** (the default) and **Bypass permissions**. A change reaches running sessions from their next step, `.env` files stay blocked in every mode, and your earlier choice carries over.
- **One Changes view**: the session's changes and everything else git reports, with the branch and commits to push or pull, in one view.
- Fetching a built-in provider's models now offers only the ones its server lists for your login.

Copies running 0.3.1 can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.4.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.4.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.4.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.4.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
