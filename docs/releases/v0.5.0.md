Trivium 0.5.0 draws Mermaid and PlantUML diagrams in the Markdown preview and lets each mode manage its skills in Settings.

- **Diagrams in Preview**: fenced `mermaid` and `plantuml` (or `puml`, `uml`) blocks in a Markdown file show as diagrams. Mermaid works out of the box. PlantUML uses the copy on your computer: set `PLANTUML_JAR` to a `plantuml.jar` and have Java installed, or put a `plantuml` command on your PATH. Diagrams show as images and never run scripts, and PlantUML can't read other files or the network.
- **Skills in Settings**: each mode lists the skills it loads, with a switch to turn one off for that mode only. Create, edit, delete or upload skills (a folder, a `.md` file or a `.zip`/`.skill` archive), or **Customize** a built-in one to edit a copy.
- A queued message now has its own edit button, and the summary cards stay in view above a long conversation in a narrow pane.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.5.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.5.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.5.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.5.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
