Trivium 0.6.0 adds a safer way to clear sessions, a setting for how wide the conversation runs, and a Write panel that shows your document from the start.

- **Archive sessions**: a session's sidebar menu now archives it instead of deleting it. Archived sessions leave the sidebar and search and wait under **Archived**, the one place to restore or delete a session.
- **Conversation width**: **Settings → General → Appearance** lets the conversation and message box grow past the old 720px limit, up to the full width of the pane.
- **Write's panel**: the document shows as soon as the session reads a Markdown or text file, edits any file, or a path is opened, with a Review tab while there are edits. File paths in Write's conversation open in the panel.
- Services are found more reliably: a dev server still shows when a read of the process list fails, and on Windows so do programs started with `Start-Process` through npm, npx, pnpm, yarn or a `.bat` file.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.6.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.6.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.6.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.6.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
