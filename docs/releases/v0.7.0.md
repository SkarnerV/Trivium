Trivium 0.7.0 puts your repository's history in Code's panel, lets you revert one file at a time, and clears committed files from the session on its own.

- **History**: a new tab draws every branch, remote branch and tag as a commit graph. Click a commit to see who wrote it, its message and the files it changed, and click a file to read its diff in that commit. Open it from the **History** button under Changes or from the summary cards.
- **Revert one file**: each file under **This session** has its own revert button, and the button under the list is now **Revert all**.
- **No more Keep changes in Code**: a file leaves **This session** once it is committed, so reverting can't undo committed work. Files changed again after their commit, staged files and gitignored files stay listed.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.7.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.7.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.7.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.7.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
