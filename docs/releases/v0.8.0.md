Trivium 0.8.0 lets you delete a session from its right-click menu, groups archived sessions by workspace, and simplifies the Changes view.

- **Delete from the session menu**: right-click a session and **Delete session** sits under **Archive session**, so a session no longer has to be archived first. It asks before deleting and moves the session to the Trash.
- **Archived by workspace**: the Archived panel lists sessions under a heading for each folder.
- **A simpler Changes view**: **History** and **Revert all** are gone from under Changes. Open History from its summary card, and revert files one at a time with each file's own button.
- **Full width fix**: the conversation text keeps the same inset from the message box as at the other widths.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.8.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.8.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.8.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.8.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
