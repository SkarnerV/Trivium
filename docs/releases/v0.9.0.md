Trivium 0.9.0 keeps a long-running command from holding up its session, without losing the work.

- **Long commands move to the background**: a command still running after 10 minutes stops holding up its session and carries on as a service, with its output in a log. When it ends, the session gets a message with the exit code and last output, and the model carries on from there. A timeout the model sets never kills the command. **Stop** in Services ends it, and a command is ended after 4 hours.
- **Turn it off per mode**: this comes as the `long-commands` extension under **Settings → Code → Extensions**. With it off, a command holds its call until it ends, and a timeout kills it, as before.
- **Services on Windows**: services no longer vanish from the list when one process's environment can't be read.

Copies running 0.3.1 or later can update from inside the app. Windows copies on 0.2.5 or 0.3.0 need to download this version by hand once, as described in the [0.3.1 release](https://github.com/SkarnerV/Trivium/releases/tag/v0.3.1).

See [CHANGELOG.md](https://github.com/SkarnerV/Trivium/blob/v0.9.0/CHANGELOG.md) for the full list.

### Downloads

- **Windows x64:** download `Trivium-0.9.0-Windows-x64.zip`, extract the whole archive once, and run `Trivium.exe` inside the extracted folder. Keep the executable and its accompanying files together.
- **macOS Apple Silicon:** open `Trivium-0.9.0-macOS-arm64.dmg` and drag Trivium to Applications.
- **macOS Intel:** open `Trivium-0.9.0-macOS-x64.dmg` and drag Trivium to Applications.

These preview builds are unsigned and the macOS builds are not notarized. Windows SmartScreen or macOS Gatekeeper may show a warning. On macOS, you may need to allow the app in System Settings → Privacy & Security after the first launch attempt.

Connect a model provider in **Settings → Models and logins**. Trivium shares sessions and logins with the pi CLI in `~/.pi/agent`; app preferences live in `~/.trivium`.

Node.js is bundled for the app and its extension helpers. Coding tools still need a shell and any project-specific tools; on Windows, install Git for Windows to provide Bash.
